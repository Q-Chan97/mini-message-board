# Shopping Cart

This is a mini message board project created as part of The Odin Project's NodeJS course. 

This project is meant to showcase my understanding of:
   - The Express framework (middleware, static assets, error handling)
   - Server-side rendering
   - Multi Page Applications
   - Routing
   - The MVC pattern

The technologies I used for this project are: 
   - Express
   - EJS
   - PostgreSQL

This project features:
   - A message board where users can submit and view messages
   - Form handling with POST requests and server-side redirects
   - Dynamic routing with parameterized URLs
   - Static asset serving
   - 404 and error handling middleware
   - SQL database querying
